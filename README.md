# Açaí do Bom — Cardápio e Gestão

Sistema de cardápio digital com carrinho, adicionais por etapas, checkout, entrega ou retirada, meios de pagamento, pedidos e painel administrativo.

## Funcionalidades

- Cardápio responsivo por categorias
- Produtos com grupos de adicionais obrigatórios e opcionais
- Carrinho e checkout em três etapas
- Endereço completo de entrega
- Nota personalizada do pedido para WhatsApp e e-mail
- PIX, dinheiro, cartão na entrega e link de pagamento
- Gestão de produtos, categorias, pedidos, preços, logo e banner
- Meta Pixel, Google Tag Manager e GA4 configuráveis
- Banco de dados e uploads persistentes
- Painel administrativo protegido

A versão de produção é publicada separadamente; este repositório mantém o código-fonte do projeto.
